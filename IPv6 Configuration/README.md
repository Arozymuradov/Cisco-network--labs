# IPv6 Configuration Lab

## Overview
This Packet Tracer lab demonstrates the configuration of IPv6 in a small enterprise network.

## Objectives
- Configure IPv6 addresses on router R1 interfaces.
- Configure static IPv6 addresses on all PCs.
- Configure IPv6 default gateways.
- Enable IPv6 routing on the router.
- Verify IPv6 connectivity between different LANs.

## Network Topology
The network consists of:
- 1 Cisco 2911 Router
- 3 Cisco 2960 Switches
- 6 PCs
- 3 IPv6 /64 LANs

### IPv6 Networks
| Network | Prefix |
|----------|----------------------|
| LAN 1 | `2001:DB8:0:10::/64` |
| LAN 2 | `2001:DB8:0:20::/64` |
| LAN 3 | `2001:DB8:0:30::/64` |

## Skills Practiced
- IPv6 Addressing
- Static IPv6 Configuration
- IPv6 Default Gateway Configuration
- IPv6 Unicast Routing
- Connectivity Verification using `ping`
