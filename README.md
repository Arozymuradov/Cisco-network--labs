# Cisco Networking Labs and Projects

## Overview

This repository showcases hands-on Cisco networking labs and projects focused on network design, configuration, administration, security, and troubleshooting.

The projects demonstrate practical experience with Cisco networking technologies, including routing and switching, IP addressing, network segmentation, and enterprise network infrastructure.

## Technical Skills

- **Routing:** Static Routing, OSPFv2, inter-VLAN routing, Router-on-a-Stick (ROAS).
- **Switching:** VLANs, 802.1Q trunking, EtherChannel (LACP/PAgP), STP.
- **Network Addressing:** IPv4/IPv6, TCP/IP, VLSM, subnetting.
- **Network Security:** Access Control Lists (ACLs), SSH, port security.
- **Network Services:** DHCP, DNS, NAT/PAT.
- **Troubleshooting:** Network connectivity testing, routing verification, and Cisco IOS diagnostics.

## Tools and Technologies

- Cisco Packet Tracer
- Cisco IOS Command-Line Interface (CLI)
- PuTTY
