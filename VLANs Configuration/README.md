# VLAN Configuration Lab

## Overview
This Packet Tracer lab demonstrates basic VLAN configuration on a Cisco switch. The network is divided into three VLANs, each representing a separate department with its own IPv4 subnet.

## Objectives
- Create VLANs on the switch.
- Assign switch ports to the correct VLANs.
- Name the VLANs as FAU, HR, and Sales.
- Configure IPv4 addresses and subnet masks on PCs.
- Verify connectivity between PCs in the same VLAN.

## VLANs

| VLAN | Department | IPv4 Network |
|------|------------|--------------|
| VLAN 10 | FAU | 192.168.10.0/27 |
| VLAN 20 | HR | 192.168.10.32/27 |
| VLAN 30 | Sales | 192.168.10.64/27 |

## Skills Practiced
- VLAN creation
- VLAN naming
- Access port assignment
- IPv4 subnetting
- Basic connectivity testing
